# Cosmic Atlas

High-end interactive Solar System explorer built with HTML, CSS and Three.js.

## Structure
- `index.html` — application
- `data/planets.json` — supplied planetary dataset
- `data/moons.json` — moon dataset used by the scene
- `assets/textures/` — optional local texture overrides

## Run
Serve the folder from a local/static web server. Direct `file://` opening can block JSON fetches in browsers.
